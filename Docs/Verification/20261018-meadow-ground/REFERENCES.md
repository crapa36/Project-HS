# 지면 레퍼런스: 확인한 사실과 HS 적용 제안

## 실제 제작자 1차 자료

1. [Jouke Jan Timmermans — Kingdom Come Deliverance 2 | Pre Production](https://jouke.artstation.com/projects/AZXxmz)
   - 본인이 Warhorse 재질 팀에서 Substance Designer/Painter로 신규 재질·기존 자산 개선을 수행했다고 설명한다. 페이지는 Road Dirt, Terrain Grass Dirt, Terrain Grass Variations, Drainage, Path Dirt를 분리하고 Substance 제작과 CryEngine 적용을 함께 명시한다.
   - **범위:** 프리프로덕션 작업이다. 출시 버전의 최종 셰이더나 품질·수치를 증명하지 않는다.
   - HS에 참고할 점(해석): 도로 흙·초지 혼합·배수 흔적을 구분된 재질 상태로 다루고 실제 장면에서 함께 평가한다. 흙 전체를 한 가지 밝기 또는 wetness로 처리하는 방식보다 현재 요구에 적합하다.

2. [Stefan Groenewoud — Working on Horizon Forbidden West as a Technical Artist](https://80.lv/articles/working-on-horizon-zero-dawn-as-a-technical-artist)
   - 제작자 직접 인터뷰. Photoshop 중심 작업에서 Substance로 전환하고 일부 암석에 photogrammetry를 사용했다고 설명한다. 공유 노드와 일괄 내보내기로 재질의 외형을 한곳에서 조정하는 장점을 강조한다.
   - **범위:** 흙 roughness/albedo 수치나 도로 생성 알고리즘은 공개하지 않는다. photogrammetry 언급을 해당 도로가 스캔 자산이라는 증거로 확대하지 않는다.
   - HS에 참고할 점(해석): 흙 색, 눌린 흔적, 젖음, 지형 변위를 동일한 도로·흔적 좌표에 연결한다. 서로 다른 noise/seed로 따로 바꾸면 색과 실제 패임이 어긋난다.

## 이미지 확인 상태

원문 텍스트와 캡션은 읽었다. ArtStation 직접 접근은 보안 challenge, 사용 가능한 브라우저는 0개이며 IAB 생성도 불가했다. 따라서 이미지를 직접 픽셀로 확인한 색·거칠기·바퀴자국 가장자리 관찰이나 저장된 스크린샷은 **없다**. 아래는 AAA 이미지에서 측정했다는 주장이 아니라 사용자 요구와 물리적 형태를 바탕으로 한 적용 제안이다. 외부 자산은 복사하지 않았고 설치도 하지 않았다.

## 지금 적용 가능한 좁은 방향

- **흙 색:** 장면 전체 exposure/UI를 바꾸지 말고 흙 재질의 밝은 베이지 성분을 먼저 낮춘다. 고정 exposure에서 흙/잔디/물의 상대 밝기를 확인한다. 스크린샷의 조명을 albedo로 착각해 RGB를 추출하지 않는다.
- **건조와 젖음:** 건조 흙의 넓은 무광 영역과 낮고 젖은 부분의 제한된 반사를 분리한다. wetness가 실제 패임·수면 마스크에 연결되어야 한다. roughness 숫자는 레퍼런스가 공개하지 않았으므로 임의의 'AAA 표준값'을 만들지 않는다.
- **바퀴자국의 위치:** 도로 중심선의 진행 좌표와 횡방향 거리로 두 자국을 만들고, 양쪽 자국·밀려난 흙 가장자리까지 도로 내부 폭 안에 제한한다. 길과 무관한 월드 좌표 스트라이프는 피한다. 도로가 휘면 접선·횡방향도 같이 변해야 한다.
- **형태:** 일정 깊이의 매끈한 두 홈보다 깊이가 끊기고 폭이 약간 변하는 패임, 바퀴 양쪽의 낮은 흙 융기, 사이에 남은 중앙 능선이 필요하다. 큰 요철은 geometry/height, 작은 흙 알갱이는 normal/roughness로 나눈다. 화면 전체를 고주파 noise로 덮으면 주행 흔적의 방향성이 사라진다.
- **계약:** 지면 높이·법선·흙색·젖음·물 depth의 흔적 좌표가 일치해야 한다. 현재 LOD에서 보존한 wet support와 경계 높이 0 계약은 유지한다. 물을 새 깊이에 맞추지 않은 채 지형만 패면 물이 뜨거나 매몰될 수 있다.

권고 우선순위: **도로 안의 자국 정합 → 흙의 과도한 밝기 완화 → 큰 패임/낮은 융기 → 작은 재질 디테일**. 이 제안만으로 AAA 품질 달성이나 성능 개선을 완료했다고 판정하지 않는다.
추가 공식 자료: [Horizon Zero Dawn Remastered 제작 설명](https://blog.playstation.com/2024/10/17/horizon-zero-dawn-remastered-a-deep-dive-into-its-enhancements/). 기존 미술 방향에 맞춘 개별 terrain material 조정과, 필요한 표면에서 텍스처·blend map·지원 geometry를 함께 제작했다는 설명을 참고했다. 특정 게임의 색/셰이더/자산을 복사하지 않았다.

## 사용자 제공 7장: 이번 수정의 우선 기준

대화에 첨부된 7장 모두 직접 확인했다. 로컬 Desktop 경로는 현재 도구에서 파일을 찾지 못했으므로 별도 원본 복사/파일 해시는 없다. 이미지의 제작 출처나 실시간 게임 성능은 확인하지 않았다.

- 1번: 밝은 판타지 숲길의 경계 식생과 색 덩어리. 노란 길 색을 그대로 채택하지 않는다.
- 2번: 두 바퀴 홈, 낮고 평평한 국소 물고임, 중앙 잔디 능선과 불규칙한 흙 가장자리.
- 3번: 발자국 주변 흙덩어리·미세 입자·부분 물고임. 현대 신발/타이어 패턴을 중세 수레에 복사하지 않는다.
- 4번: 식생과 소품의 실제 크기 관계. 각진 저폴리 소품 스타일은 최종 재질 기준으로 혼합하지 않는다.
- 5번: 길을 따라 묶인 생활 소품과 꽃·풀 군집, 큰 빈 공간. 마을 건축 제작으로 범위를 넓히지 않는다.
- 6·7번: 전체 목표. 길 안의 읽히는 바퀴 패임, 밀린 흙 융기, 부분적으로 묻힌 자갈, 소품 주변 식생, 건조/습윤/물의 분리. 현재 HS가 이 품질에 도달했다는 뜻은 아니다.

실제 카메라는 유지한다. 근접 참고 이미지의 픽셀 밀도를 원거리 게임 화면과 동일하게 비교하지 않으며, 조명을 바꾸거나 별도 Blender 렌더로 런타임 품질을 대신 증명하지 않는다.
