이전 보고의 V01 보류·A03/A05 조사 부족은 후속 구현 이전의 상태다. 현재 실제 이동 경로 CCD, 광원 bitmask 및 소비자별 auxiliary 생존 처리를 유지하며 기존 회귀 근거와 현재 연결을 다시 대조했다. A07은 narrow/full 연결 오류 수정과 scene closure 사전 거부를 유지한다. V04/A01/A04/A06/A09의 범용 구조 변경은 현재 결함이나 측정된 병목을 해결한다는 근거가 없어 추가하지 않는다. 이는 모든 조건부 경로가 검증됐다는 의미가 아니다.

이번 A05 추가 변경은 기존 5프레임 fixture의 설정·resize·Render·capture 구간 측정과 SSS 생존 유지·실제 할당 일치 검사다. GPU 검증 지연을 자원 재생성 시간과 구분하기 위한 것으로, 품질·판정 기준이나 600초 한도를 낮추지 않았다.

추가 조사에서 Windows 200% 배율의 실제 시작 오류를 발견했다. 같은 DISPLAY2의 CCD 물리 크기 1920×1280과 DPI-unaware 모니터 크기 960×640을 비교해 출력 선택이 실패했다.
