## 검증 기록의 범위

- 기존 core 10/10과 C01/C02의 좁은 CPU 회귀, shader arithmetic/source/ABI 8검사는 완료된 개별 근거다. CPU 모델이나 source 검사는 compiled shader 실행·GPU 분기 oracle·thread sanitizer의 대체물이 아니다.
- 수정 후 `verify-portable` 전체 **23/23 통과** (`Build/verification/review-portable-final.log`, 51.81초). 이전 generation-lifetime 실패는 제품 소실이 아니라 269자 Windows 경로 관측 문제였고, 확장 경로로 원래 `X`를 확인한 뒤 fixture 이름만 단축했다. 원래 제품 보존 assertions는 유지했다.
- 전체 실행 `verify-20261010T094257223Z-4768`은 **76/77 통과**했고 카메라 fixture만 실패했다. fixture의 가림·clipping 격리 후 `verify-20261010T101003093Z-34424`에서 camera/analyzer **2/2 통과**했다. OIT 실제 raw 분석은 `Build/reviews/consolidated-20261010/oit-after-analysis.json`이다. 최신 기록의 runtime-full generation은 `86c6bb06570d2b8c6b4199eb0418247b776b482b0dd1aaafd9cd6498a70381f1`, 3,680제품이다.
- resident/probe 수정 후 `verify-20261010T102630399Z-33072`의 shader reload·material reload·local-probe **3/3 통과**. full-resident Runtime 연결 후 `verify-20261010T104523795Z-9732`의 확장 shader reload·watch·architecture **3/3 통과**. 실제 log는 원래 resident ID로 narrow frame 59, 비호환 layout 거부, 새 resident ID로 full frame 156을 확인한다. D3D12 validation 0, static scene upload 2, 정상 종료 0이며 원본 포인터를 보존했다. 서로 유효한 개별 결과를 통합하며 한 번의 78/78 전체 gate 통과로 기록하지 않는다.
- 최신 Release FHD Ultra 240틱 두 실행은 60 warmup 프레임 제외 render-scope p50 **60.5075/60.7185ms**, p95 **68.699/68.683ms**다 (`Build/reviews/consolidated-20261010/performance-after.json`). lockstep의 매 프레임 전체 GPU queue drain을 포함한 scope이며 실제 display FPS가 아니다. Release 최적화와 validation/GBV OFF, RTX 4080은 확인했으며 임시 flicker probe는 제거돼 있다. 종료 후 readback은 프레임별 scope 밖이다. 과거 49.8645ms는 direct-root b0 정확성 수정 이전이라 동등 A/B나 이번 변경의 성능 인과로 쓰지 않는다.
- 최종 Release `ProjectHS`/`hs_render_test_runner` 빌드와 3,680제품 검증 성공 (`Build/verification/review-release-completed.log`). 같은 FHD Ultra 프로필의 일반 Runtime 60초 입력은 lockstep·VSync·frame cap 없이 정상 종료했다 (`Build/verification/review-final-normal.log`). 1,021프레임, checksum `15682705976600721736`, validation/drop/unsupported 0이다. tick 300 이상·게임 종료 tick 1818 미만의 456프레임 Render scope p50 **55.37ms**, p95 **60.41ms**이며 Render 이전 CPU 준비는 포함하지 않는다 (`Build/reviews/consolidated-20261010/normal-play-after.json`). 실제 present 간격 계측은 아니며 144FPS 목표는 미해결이다.
